# 网页奖励 OCR（试用）

不安装客户端、扩展或本机服务。开核桃页面提供三种输入：共享画面按次识别、粘贴 / 导入截图、手动输入四个奖励。

## 点击识别

1. 用桌面版 Chrome / Edge 打开虚空账本 → 开核桃助手。
2. 选择中文 + 英文或仅英文，设置实际奖励数（1–4）。点击“共享游戏画面”，在浏览器的授权对话框选择游戏窗口或游戏所在屏幕，**不要选择虚空账本标签页**。每次新会话需要重新授权；网页无法绕过。
3. 初次需要从本站下载 OCR 组件、WASM 和识别模型，耗时取决于网络；仅英文较快。下载完成后识别在浏览器本机完成，不上传图像。浏览器可能缓存模型，但不保存游戏截图。
4. 检查绿色区域：左右区域均分成奖励数个格子，上下范围覆盖每个奖励的**完整名称**。不同分辨率、UI 缩放、超宽屏和人数布局需要校准。区域可在识别轮次间调整，下一轮生效。
5. 共享完成后等待你点击“识别一次”，不会自动提取画面帧或运行 OCR。奖励出现后，在网页或悬浮价格窗点击按钮，一次处理当前一帧的全部奖励，完成后保留结果；下次需要时再点。识别期间按钮禁用，避免重复任务。屏幕共享流在停止共享前仍保持连接。
6. 网页放副屏即可查看。较新的 Chrome / Edge 支持 Document Picture-in-Picture 时，“悬浮价格窗”可尝试在游戏上方显示结果。浏览器在后台可能限速，无法保证即时识别；独占全屏可能无法捕获或覆盖，建议窗口 / 无边框模式。
7. 点击“停止共享 / 取消识别”、浏览器原生“停止共享”、关闭网页或切离开核桃功能会停止共享并清除帧和结果。不会后台继续采集。

纯网页无法响应游戏前台的全局快捷键或静默截屏；从共享画面识别依赖用户主动授权的屏幕共享。无需在游戏里触发网页快捷键。

## 反作弊边界

当前实现只处理用户明确导入的图片，或浏览器屏幕共享授权返回的画面帧。代码使用标准浏览器的 `getDisplayMedia`、`createImageBitmap`、Canvas 和 Tesseract.js；**没有打开 Warframe 进程、读取 / 写入游戏内存、扫描游戏文件、注入 DLL、模拟按键 / 鼠标或与游戏进程通信的代码**。OCR 识别在网页 Worker 中执行。

这说明本工具的实现路径不涉及游戏内存读取，但不能替 Digital Extremes 对游戏规则作解释，也不能承诺任何第三方程序在所有环境下都绝无封禁风险。若你希望采取最保守的方式，可以只用 Windows 自带截图工具截取一次、手动切回网页导入图片并识别；无需启用屏幕共享。

## 手动截图

使用 Windows 截图工具截取奖励界面（全屏截图更容易沿用相同的区域设置），切回开核桃页面，在未聚焦输入框时按 Ctrl + V，或点“选择奖励截图”。确认区域后点击“识别一次”。只在本机解析图片，不发送到服务器。若网络不允许加载 OCR 组件，可手动输入每行一个完整奖励名称。

## 匹配与价格

- 候选仅为当前遗物掉落目录的 596 种奖励（594 种可交易商品和两种 Forma），不会把所有 WFM 商品都当成奖励。
- 使用中英文名、标点 / 空格归一化、精确部件名和名称换行组合匹配；相似度和首两个候选的差距用于筛选近似匹配。这里的“近似”不代表经过校准的识别置信概率。
- 同格出现多个精确奖励名会提示歧义，避免裁切跨格后直接选错。中文 OCR 错字、部位漏字时允许搜索并手动确认。
- 只有完整名称精确匹配或手动确认，且公开在线卖价在 6 小时内、最近查询未失败，才参加“已确认奖励中挂价最高”提示。未确认、缺价、旧值不参与；相同价格可同时标记。
- 标记仅比较当前已确认且有有效报价的奖励，并不保证缺价或未识别的奖励更便宜。
- 价格沿用网站的 WFM **公开行情快照**，不是实时接口查询或成交承诺；保留商品原始报价时间，Forma 显示不可交易。

## 隐私与实现

- 使用 Tesseract.js 5.1.1（Apache-2.0）与 tesseract.js-core / Tesseract 中英模型。固定版本的组件与模型随网站部署、从本站加载，不依赖外部 OCR CDN。许可与来源见 `static/ocr/NOTICE.md`。没有截图上传 API、个人账号接口或本机连接器。
- 图片、共享流及 OCR 结果仅保存在当前页面内存；不写入浏览器库存、备份或 GitHub。关闭 / 停止后清除共享画面与结果，关闭页面释放 OCR 引擎。截图文件只有用户主动选择时才读取。
- `static/reward-ocr-core.js`：归一化、候选匹配、换行组合、报价与推荐规则；Node 测试覆盖。
- `static/reward-ocr.js`：网页输入、共享流生命周期、OCR Worker、区域预览、取消与可选画中画。
- `static/extras.js`：开核桃模块挂载、更新价格、离开时停止采集。

首版没有真实 Warframe 奖励截图与 Windows 游戏环境实测，不能承诺识别准确率或固定耗时。浏览器功能支持、网络模型加载及共享授权需要在用户自己的浏览器验证。
