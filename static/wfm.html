连接你的 WFM 会话

先在 WFM 官网登录 ↗，然后把当前会话的 Authorization，或单独的 JWT Cookie 值（写成 JWT=值）粘贴到这里。它只交给本机服务，关闭服务或断开后清除，不保存到浏览器或文件。

如何取得会话授权？
  1. 在你常用的浏览器登录 WFM 官网，不要在聊天或本网页输入 WFM 密码。
  2. 打开开发者工具的 Network / 网络面板，刷新 WFM 的个人挂单页面。
  3. 选择发送到 api.warframe.market 的本人账号 / 挂单请求，在 Request Headers 找到 Authorization，复制完整值。
  4. 如果请求没有 Authorization：可到开发者工具 Application / 应用 → Cookies → warframe.market，找到 JWT；仅将其值以 JWT=值 的形式填到此处。不要复制整段 Cookie 或 curl。此方式会转为旧版 JWT Authorization，兼容性以实际验证结果为准。
  5. 仅粘贴到此本机窗口；这里会通过官方 /me 接口核实账号，再显示本人挂单。

当前官方公共 OAuth 尚未开放，这是现有会话接入方式，不是 WFM 官方授权页。请勿复制整段 Cookie 或把令牌发给别人。会话过期、服务重启后需要重新连接。
