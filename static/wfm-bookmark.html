① 拖到浏览器书签栏

按 Mac ⌘⇧B / Windows Ctrl+Shift+B 显示书签栏，将下方按钮拖进去。书签名称可以改为「虚空账本」。已有旧书签也需要重新拖入替换；自包含书签不会自动更新。

◈ 虚空账本

这里是书签脚本，需在 WFM 官网点击收藏后的书签。在此页面直接点击只会提示操作位置。

拖拽不方便？手动添加书签

新建一个书签，将下面的完整内容设为书签网址（需保留 javascript: 开头）。这是本项目源码，不含你的个人信息。

② 登录官网，点击书签

  1. 打开 WFM 官网 ↗，在你常用的浏览器里登录。
  2. 保持 WFM 页面打开，点击书签栏里的「虚空账本」。右上角应出现 v0.2 挂单管理面板。如果还显示旧版「只读测试」，先刷新 WFM 页面，再点击新书签。
  3. 点击「同步我的挂单」。读取中文商品名后，可搜索、筛选买卖 / 显隐，编辑价格与数量；点击「预览修改」或上下架按钮，核对账号、商品变体和旧值 → 新值，再确认提交。

已支持什么？还有什么待验证？

已实现全部本人挂单同步、官方中文目录、中英文搜索、买卖与状态筛选、逐条价格 / 数量修改、逐条及勾选批量上下架。上 / 下架仅改变已有单的显示状态。新建挂单仍需到 WFM 官网操作，不删除、不标记成交。

书签不读取 Cookie、JWT 或浏览器存储，只向官方 API 请求，浏览器按自身规则携带会话；公共商品目录请求不携带凭据。不会把挂单或凭据传回行情网页，不加载远程脚本。

浏览器、WFM 页面安全策略、跨域校验或会话机制均可能使测试失败。失败会显示原因，无法读取不会被算作“库存为空”。

使用者已反馈真人账号读取成功（含隐藏单）；价格 / 数量 / 显隐的真实写入仍待验证。已通过模拟测试核对预览不写、准确字段、变体保留、官网冲突、过期 / 重复提交与超时回读。自动化浏览器禁止执行 javascript: 书签，因此真实写入需你在常用浏览器自行选择一条挂单验证。无需发送凭据。

首次只选一条需要变更的挂单。每次提交前重新确认账号与版本，提交后回读核实。遇到权限 / CSRF 校验拒绝、限速或结果不明会停止，不自动重试。批量操作可能部分完成，已成功项不会自动回滚。
