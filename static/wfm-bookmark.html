① 拖到浏览器书签栏

按 Mac ⌘⇧B / Windows Ctrl+Shift+B 显示书签栏，将下方按钮拖进去。书签名称可以改为「虚空账本」。

◈ 虚空账本

这里是书签脚本，需在 WFM 官网点击收藏后的书签。在此页面直接点击只会提示操作位置。

拖拽不方便？手动添加书签

新建一个书签，将下面的完整内容设为书签网址（需保留 javascript: 开头）。这是本项目源码，不含你的个人信息。

② 登录官网，点击书签

  1. 打开 WFM 官网 ↗，在你常用的浏览器里登录。
  2. 保持 WFM 页面打开，点击书签栏里的「虚空账本」。右上角应出现测试面板。
  3. 点击面板里的「读取我的挂单」。结果会区分账号请求、挂单请求和具体 HTTP 状态。

这一步验证什么？

当前只实现读取账号和挂单，保留买单与隐藏单的区别。改价、数量修改和上下架尚未开放；读取成功也不能证明有写入权限。

书签不读取 Cookie、JWT 或浏览器存储，只向官方 API 发送两次 GET 请求，并让浏览器按自身规则携带会话。不会把挂单或凭据传回行情网页，不加载远程脚本。

浏览器、WFM 页面安全策略、跨域校验或会话机制均可能使测试失败。失败会显示原因，无法读取不会被算作“库存为空”。

当前自动化浏览器禁止执行 javascript: 书签，因此尚未在真实 WFM 会话中验证。需要你在常用浏览器手动点击测试；无需发送任何凭据。
