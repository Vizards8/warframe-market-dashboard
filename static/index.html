随时打开，按需刷新。

以后双击文件夹里的「打开行情.command」，即可启动并打开网页。启动后的终端窗口可以关闭。

库存行内可直接输入或用加减按钮调整；目标价、成本、笔记修改后自动记住，不需要保存或导入导出。关闭网页后仍保留；换浏览器、设备或清除网站数据后不会同步。

打开页面时会自动刷新超过 6 小时未更新的库存；P 甲、MOD 和 0 洗紫卡按需点击刷新。进度条显示已完成的查询数和百分比。网络失败时保留旧值，并标记失败；旧值不等于当前行情。

MOD 全部按 R0；P 甲为蓝图套装；武器按可交易状态。成交估值不是利润，也不保证一次售完。目标价默认留空，不替你决定卖点。

返场日期来自人工核对，不会随刷新自动更新；商品详情可以手动修改。页面只查询行情，不替你发布挂单或交易。开核桃助手可预先选择四个遗物，查看所有掉落的实时挂价；“全屏对照”方便奖励选择时查阅。紫卡为 0 循环的公开直售挂单，不是成交价。

点击“备份库存”下载 JSON，在在线版或另一台电脑点击“导入库存”即可迁移；文件只在浏览器读取，不会上传。导入会更新同名商品，其余当前记录保留。图片需联网。
